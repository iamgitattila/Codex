                              QUICK START (3 STEPS)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Install
─────────────────
cd preppercodex-engine
chmod +x scripts/setup.sh
./scripts/setup.sh

STEP 2: Configure
─────────────────
nano config.yaml

Add:

- WordPress credentials (REQUIRED)
- Optional: NOAA, Census, Amazon affiliate keys

STEP 3: Run
─────────────────
source venv/bin/activate
python main.py collect              # Fetch data
python main.py generate --limit 5   # Generate 5 test pages
python main.py status               # Check status
